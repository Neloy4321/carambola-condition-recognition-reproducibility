# Five-commit repository deposition

1. Initialize scope and limitations.
2. Archive dataset quality, baseline, external and efficiency results.
3. Archive capture-proxy protocol, model metrics, confusion matrices and training trace CSVs.
4. Restore exact JSON bytes and add historical analysis figures, calibration and model-comparison outcomes.
5. Add aggregate expert review and later exploratory analysis evidence, reader guidance and executable arithmetic checker.

**Important:** This GitHub mirror is a curated evidence subset rather than a complete publication-ready archive. Source photos, original image manifests, signed certificates, model weights and private crosswalks must not be uploaded until rights and consent are verified. Some public-safe historical notebooks, Python scripts, tables and figures remain in the researchers' separately prepared 93-file ZIP, not yet uploaded to GitHub.

A five-commit history is an organizational upload history; it does not prove the chronological timing of the original laboratory experiments. Source dates, original files, hashes and provenance must be independently reconciled.
