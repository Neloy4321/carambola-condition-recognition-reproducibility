# Data and access policy

**Public release:** aggregate results, methods and code only. The original photographs, image-level manifests, unredacted reviewer records and model weights are kept separately; their redistribution rights have not been established.

The original Drive dataset contains six class folders with 2,644 image files. A historical audit reports 2,583 MD5-unique images. MD5 uniqueness is not specimen or tree independence. Image collection location, tree identity and source rights remain incompletely verified.

The inspected test and external datasets are not prospective held-out evaluations. Some historical records list 2,416 images rather than the verified 2,644 file inventory. Do not assert that this discrepancy is resolved without provenance evidence.

Editor-only material should be provided through controlled, permission-verified channels, never through this public repository or public issue attachments. No public data/code reuse license is granted yet.
